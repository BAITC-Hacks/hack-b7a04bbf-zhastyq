## Что реализовано

Рабочий frontend использует `GET /api/analysis`, `POST /api/analyze`, карточки, три серверных экспорта и `/api/ask`. Преобразования полей централизованы в API-адаптере. Gid не проходят через Number; top-20 объединяется с полными узлами по строке. Поиск полный, отображается подграф непосредственного окружения. Все наблюдаемые связи доступны в карточке. Фикстуры — только в тестах, ошибки не подменяются демонстрацией.

data_gaps связаны с next_requests; временные наблюдения отображают даты, суммы, показатели и ограничения. AI — безопасный текст со ссылками. При STALE_ANALYSIS обновляется снимок; повтор вопроса только по действию пользователя. Ошибочная загрузка сохраняет прежний экран, успешная смена снимка сбрасывает старую карточку/AI.

На какие наблюдаемые признаки опирается вывод?» Ответ указал consolidator как гипотезу сбора, 24 плательщика, входящие 3 848 436 KZT, 62 исходящие связи, top_rank=1 и priority_score≈0,8517; предупредил о неполных входящих seed, неизвестном балансе и показанных 5 из 86 связей. Ссылки и суммы сверены с текущим анализом. Виновность не утверждается. Проверка ссылок не доказывает истинность любого свободного текста LLM.

## Что не удалось проверить

`docker compose` в WSL сообщает, что Docker Desktop integration не включена. Windows docker.exe не находит pipe `dockerDesktopLinuxEngine`. Систему и Docker не переустанавливали.

Установленный Windows Compose **v2.38.2-desktop.1** успешно выполнил `-f compose.yaml config --quiet`, без печати подставленных секретов. Это проверка конфигурации, не работа Engine. **Образы не собирались, контейнеры не запускались**; mount/volume, контейнерный DNS и healthcheck в контейнере пока не проверены. Локальная браузерная проверка не заменяет этот шаг. После запуска Engine и WSL integration выполнить из корня `docker compose up --build -d` и повторить smoke.

Один процесс backend, один активный анализ в памяти. После рестарта нужна загрузка заново. Нет авторизации/TLS/публичного production-развёртывания. На большем графе текущая передача полного анализа и поиск в памяти потребуют пагинации/индекса; новые алгоритмы не добавлялись. Методика и ограничения наблюдения остаются в backend README.
