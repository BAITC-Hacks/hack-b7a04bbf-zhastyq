# Блок графа HackAlem

Изменения изолированы в `src/features/graph/`. `GraphView` по-прежнему принимает исходный `GraphViewProps`, получает `GraphSlice` через props и передаёт исходный строковый `gid` в `onSelectGid`. HTTP-запросов, новых зависимостей, изменений аналитики и фикстур в production-компоненте нет.

## Вид и управление

Референс `m2-res_1080p.mp4` просмотрен в моменты 0, 5, 10, 15, 20, 25, 30, 35 и 39 секунд: общий вид, регуляторы, приближение, соседство и фильтрация. Использованы белое поле, тонкие полупрозрачные линии, небольшие узлы, панель шириной 236 px, разделители, компактные переключатели и фиолетовый акцент. Окружающий интерфейс не менялся. Силуэт определяется входными связями; узлы для сходства с видео не добавляются.

- Поиск точного `gid` проверяет все узлы загруженного среза. Скрытый результат можно раскрыть со сбросом фильтров; изолированный результат тоже доступен. Идентификаторы никогда не преобразуются в числа.
- Фильтры: seed, изоляты в текущем индуцированном подграфе, роль, кластер и точная глубина из данных. Отсутствие исходящих переводов не меняет роль.
- Переключение цвета по роли / кластеру обновляет легенду. Форма продолжает обозначать роль. Существующие цвета ролей сохраняются.
- Подписи появляются от zoom 1.7; выбранный и наведённый узлы подписаны всегда. Seed имеет двойную обводку и подпись `S <gid>`.
- Hover выделяет непосредственное соседство, после ухода восстанавливается внешний `selectedGid`. Выбор доступен также через поиск, а сведения о выбранном узле остаются текстом под Canvas и в родительской карточке.
- Колесо приближает относительно указателя; фон перемещается, узлы перетаскиваются. Доступны fit, +/−, сброс вида и фокус на выбранном узле. На Canvas работают клавиши +, −, 0.
- Сброс настроек восстанавливает фильтры, отображение и силы, сохраняя загруженные данные и выбор. Панель закрывается и открывается; при ширине блока меньше 640 px она изначально свёрнута.

## Размеры, токены, направление

`graphStyles.ts` читает `getComputedStyle(document.documentElement)` и наследуемые значения контейнера. Цвета проверяются через `CSS.supports`, числа ограничиваются конечными диапазонами, формы — допустимым набором. CSS `var()` не передаются в Cytoscape. Обновление атрибутов темы на root/body/блоке и системной цветовой схемы обновляет стили без пересоздания Canvas.

В общем `tokens.css` роли пока заданы кругами. Требуемые формы переопределены только в `.aml-graph`: consolidator → hexagon, transit → ellipse, distributor → triangle, terminal → round-rectangle, coordinator → diamond, peripheral → octagon.

Площадь узла линейна по ограниченному `priority_score`:

`diameter = sqrt(min² + (max² − min²) × clamp(priority_score, 0, 1))`.

При текущих токенах базовые диаметры 6–18 модельных px, пользовательский множитель 0.5–1.8. Seed не увеличивает размер. Метрика и роль не выводятся из положения или степени узла.

P95 вычисляется по конечным неотрицательным `sum_kzt` валидных рёбер всего полученного GraphSlice, до визуальных фильтров. Сохранена логарифмическая нормировка:

`width = min + (max − min) × min(1, log1p(max(0, amount)) / log1p(max(P95, 1)))`.

Обзорные границы — общие токены ширины × локальный коэффициент 0.5, сейчас 0.35–0.9 модельных px. Прозрачность — общий токен × пользовательская видимость, по умолчанию 0.7 × 0.5. Пустые, нулевые, одинаковые и экстремальные суммы проверены тестами. У подсвеченного ребра ширина усилена; получатель обозначен стрелкой. Встречные переводы имеют раздельные кривые; петли остаются петлями.

## Раскладка и жизненный цикл

Cytoscape.js сохранён как Canvas-отрисовщик. Проверен исходный CoSE установленной версии 3.34.3: `calculateEdgeForces` возводит отклонение длины в квадрат без смены направления. На существующей фикстуре увеличение idealEdgeLength с сохранением координат могло сокращать рёбра. Поэтому заменён только расчёт координат в worker, без замены renderer и без новых библиотек.

`forceLayout.ts` использует детерминированные исходные координаты из строкового hash, Barnes–Hut с theta 0.8 для отталкивания, знаковые пружины, демпфирование, ограничение скорости и охлаждение. Для больших графов ограничены итерации. Расчёт не содержит финансовой аналитики.

| Контроль | Реальное действие |
| --- | --- |
| К центру | Радиальное притяжение к исходному центроиду, коэффициент `center × 0.004` |
| Отталкивание | Взаимное отталкивание, коэффициент `80 × repulsion`, с защитой от совпавших позиций |
| Сила связей | Жёсткость знаковой пружины, `0.045 × strength`, с нормировкой нагрузки на хабы |
| Длина связей | Желаемая длина пружины — токен intra/inter × distance |

Рабочий экземпляр Cytoscape сохраняется. Элементы обновляются пакетом, для одинаковых id сохраняются позиции. Выбор, цвет и подписи не запускают раскладку. Слайдеры имеют debounce 180 ms, предыдущая задача отменяется. Worker присылает промежуточные позиции; переходы 400/650 ms выполняются через requestAnimationFrame без React state на каждом кадре. Поиск и перетаскивание отменяют устаревшее движение. Узлы не размещаются на искусственной окружности.

При движении более 1000 узлов рёбра временно используют быстрые линии между центрами; focused-рёбра сохраняют стрелки. После остановки восстанавливаются обычные стрелки и встречные кривые. Это временное упрощение только отрисовки, не направленности данных. В reduced-motion промежуточные снимки не показываются, итоговые позиции применяются без интерполяции.

IntersectionObserver и visibilitychange приостанавливают скрытый блок; при возвращении незавершённая задача продолжается из текущих позиций. ResizeObserver меняет размер Canvas без нового layout. На unmount удаляются наблюдатели, listeners, animation frames и worker, затем уничтожается Cytoscape. Проверено повторное монтирование в React StrictMode.

## Проверка

Из `frontend/`:

```sh
npm test
npm run build
```

Браузерные проверки используют отдельный перехваченный тестовый маршрут и не добавляют данные приложению. При работающем Vite и доступном Playwright:

```sh
node src/features/graph/graph.browser.test.mjs
```

Переменные: `GRAPH_PLAYWRIGHT_MODULE` — путь к установленному Playwright (если его нет в проекте), `GRAPH_QA_URL` — адрес Vite, `GRAPH_BROWSER` — канал браузера, `GRAPH_QA_OUTPUT` — папка снимков и results.json. `GRAPH_PROFILE=1` сохраняет профиль главного потока. Пакеты проекта для QA не менялись.

Проверяются интеграция callback в App, неизменность координат и viewport при выборе/стилях, hover, зум и pan, все силы, фильтры, скрытый и отсутствующий результат, длинные строковые id, seed, изоляты, несколько компонент, переключение темы, 390 px, пустые состояния, reset, StrictMode, cleanup и reduced-motion. Численные тесты проверяют именно направление эффекта сил, а не только изменение координат. Скриншоты общего вида, приближения, hover, selection, сил, фильтрации, изолята и узкого блока сделаны в Edge; крупные кадры имеют 1808×1080, как видео.

## Границы интеграции

- Доступная фикстура содержит 6 узлов и 5 рёбер, а не полный финансовый датасет. Нагрузочный граф на 2248 узлах / 3119 рёбрах — явно синтетический тест, не результаты анализа. Плотность и силуэт реального набора здесь проверить нельзя; pixel-perfect соответствие не заявляется.
- Текущий `getNodeView` возвращает подробную фикстуру только для `1005`; GraphViewProps не даёт функции поиска/загрузки вне среза. Поэтому поиск честно ограничен всеми узлами входного GraphSlice. Для полного датасета нужен доступный родительский механизм получения узла и его среза с состояниями pending/not-found/error.
- Callback принимает только `string`, родитель не снимает выбор по фону. Снятие выбора через `null` не имитируется. Для этой функции потребуется согласованное расширение контракта.
- Ошибки данных обрабатывает существующий App через WorkspaceState; GraphView показывает собственные ошибки расчёта раскладки. Контракт ошибок API не менялся.
- Сам блок проверен на 390 px, но общий app-shell по существующему CSS имеет min-width 1024 px. Глобальная адаптация приложения за пределами этой работы.
- Полная синтетическая сеть тяжелее локальных срезов: замеры worker и длинных кадров сохраняются в results.json. Гарантия FPS не заявляется; массовое перестроение и первоначальная отрисовка могут давать задержки на слабых устройствах.
