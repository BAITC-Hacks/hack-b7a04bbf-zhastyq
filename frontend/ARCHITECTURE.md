# Архитектура интегрированного frontend

React/TypeScript/Vite, Cytoscape только в `features/graph`. Светлая тема и глобальные токены сохранены. Исторические `AGENT_APP.md` / `AGENT_GRAPH.md` описывают прежнее разделение работы; интеграция выполняется последовательно по текущей задаче пользователя.

Поток: `HTTP API → shared/api/workspace.ts → useWorkspace → App/NodeCard/GraphView`. Все HTTP-запросы централизованы. Domain-правила backend не копируются в UI. Источник истины: [backend/docs/data_contract.md](../backend/docs/data_contract.md) и OpenAPI.

| Маршрут | Назначение |
|---|---|
| GET /api/analysis | Полный согласованный снимок, кластеры, top-20 |
| POST /api/analyze | Multipart из трёх Parquet, синхронный подтверждённый результат |
| GET /api/nodes/{gid} | Все связи, ограничения, рекомендации, временные наблюдения |
| POST /api/ask | Вопрос по выбранному узлу и текущему analysis_id |
| GET /api/exports/{name} | Три серверных CSV с проверкой X-Analysis-Id |

Адаптер переводит src/dst в source/target, in_kzt/out_kzt в incoming_sum_kzt/outgoing_sum_kzt, in_deg/out_deg в unique_payers/unique_recipients. TopNode объединяется с nodes по точной строке gid. Number/parseInt для идентификаторов не используются.

useWorkspace хранит полный анализ для поиска любого узла; отображаемый GraphSlice содержит выбранный узел, непосредственных соседей и внутренние связи этого среза. Изолированный узел сохраняется. Карточка проверяет analysis_id ответа, смена снимка отменяет старые запросы и сбрасывает AI-ответ. Неудачная загрузка не заменяет старый снимок. При отсутствии анализа доступен импорт; при ошибках — явное сообщение и повтор без фикстур.

AI отображается обычным текстом React, не HTML/Markdown. Ссылки по gid выбирают узел. При STALE_ANALYSIS заново получаем анализ, повтор вопроса выполняет пользователь. CSV скачиваются только с сервера; локальный topNodesCsv остался вспомогательной тестируемой функцией, не частью рабочего экспорта.

В Compose браузер обращается к Nginx; `/api/` проксируется с сохранением пути в backend:8000. Frontend не получает секретов. Отдельный dev/preview Vite имеет локальный прокси к 127.0.0.1:8000. Vite-переменные применяются на этапе сборки. Рабочий адаптер всегда реальный, fixtures используются только тестами.
