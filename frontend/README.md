# Фронтенд AML MVP

Одноэкранный интерфейс аналитика: загрузка Parquet, топ приоритетов, поиск `gid`, направленный граф и карточка узла. Бэкенд команды — модульный монолит с одним HTTP API.

## Локальный запуск

Используйте Node.js `24.11.0` из `.nvmrc` и npm `11.6.1`. Из каталога `frontend/`:

```bash
npm install && npm run dev
```

Команда поднимает одноэкранное приложение с тёмными панелями и демонстрационными данными. Подробная карточка и граф доступны для gid 1005. Выбор файлов пока не запускает анализ: подключение сервиса анализа и реального API — отдельный этап. При выключенном mock-режиме отображается сообщение о неподключённом сервисе, синтетические результаты не подставляются.

Дизайн-токены находятся в `src/styles/tokens.css` и импортируются первыми в `src/main.tsx`. Файлом владеет агент 1. Агент 2 читает глобальные `--graph-*` и `--role-*` при оформлении графа.

Для воспроизводимой установки по зафиксированному `package-lock.json` можно использовать `npm ci` вместо `npm install`.

## API и mock-режим

Без `.env` приложение должно запускаться в mock-режиме. Для явной настройки скопируйте `.env.example` в `.env`. `VITE_API_MOCK=true` означает работу со статичными синтетическими фикстурами в `src/shared/api/fixtures/`; при `false` запросы идут к `VITE_API_BASE_URL`. Обе переменные читает только API-адаптер, поэтому переключение не требует правки компонентов. После изменения `.env` перезапустите dev-сервер. Подробная фикстура пока подготовлена для `gid=1005`; другие `gid` не должны показывать её как свою.

Предварительные маршруты и типы описаны в `ARCHITECTURE.md` и `src/shared/contracts.ts`. Если фактические маршруты модульного монолита отличаются, меняйте только `src/shared/api/`.

## Передача работы между агентами

- Агент 1: `AGENT_APP.md` — экран, сценарий, API, mock/real переключатель.
- Агент 2: `AGENT_GRAPH.md` — только `src/features/graph/`.
- Общие границы файлов: корневой `AGENTS.md`.

Пустой граф — отдельный проверяемый сценарий. Визуально проверьте `graph=null`, `graph-slice-empty.json` и обычный `graph-slice.json`: вместо пустого белого поля должно быть понятное сообщение.
